# ENSL Lost Season Badges

A Natural Selection 2 mod project restoring tournament badges for NSL Seasons 13 and 14, using existing ENSL badges as the visual and behavioral reference.

**Status:** plan accepted; Workshop cover prepared. Recipient verification and runtime implementation are next. There is no playable mod yet.

- [Accepted implementation plan](PLAN.md)

The cover is available as 512 x 512 PNG and JPEG. The badge comparison shows actual installed game textures; final Season 13/14 textures remain to be made.

## Award policy

Use current ENSL standings, remove disqualified teams from the relevant competition, and promote remaining teams in order. Preserve published placement separately from the mod's promoted award.

Season 13 Division 1 bronze is omitted because the historical records are unavailable. The accepted scope contains 11 awarded team placements.

Primary results source: [ENSL Hall of Fame](https://www.ensl.org/halloffame).

## Distribution

The proposed mod grants account-specific custom badges on servers running it. It does not issue official Steam inventory items. A GitHub remote and Workshop release have not been created.
